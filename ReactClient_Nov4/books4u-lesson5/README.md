# Books 4 U -- Lesson 5 Starter

CSC3700 Advanced Web Development, Fall 2026.

This is the Books 4 U React app as it stood at the end of React Lesson 11.
It reads from JSON Server on port 3333. In Lesson 5 you switch it to your
own Express API.

## Run it

    npm install          # once, restores node_modules
    npm run server       # Terminal 1: JSON Server on http://localhost:3333
    npm run dev          # Terminal 2: React on http://localhost:5173

If you delete all the books by accident, copy db/db.original.json over db/db.json.
